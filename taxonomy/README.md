# taxonomy/biology.json
این فایل عمداً ساخته نشده است؛ فصل‌ها هرگز از حافظه‌ی مدل نوشته نمی‌شوند.
برای هر کتاب (دهم، یازدهم، دوازدهم) صفحه‌های فهرست مطالب را بدهید و اجرا کنید:

    python -m exambank build-taxonomy -n tax -i fehrest-10.pdf -p "3-4" -o <پوشه> --book-id bio10 --grade 10 --book-title "زیست‌شناسی دهم"

بعد از ساخت، فایل را با کتاب مقایسه و در صورت نیاز با دست ویرایش کنید (شناسه‌ها را تغییر ندهید).
تا وقتی این فایل نباشد، مرحله‌ی classify متوقف می‌شود و همین پیام را می‌دهد.
